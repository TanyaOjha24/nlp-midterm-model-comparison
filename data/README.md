
# Dataset

This project uses the **Tiny Shakespeare** dataset, a collection of Shakespeare's works used for character-level language modeling.

## Source

The dataset is downloaded automatically from:

https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt

## Dataset Details

- Total characters: Approximately 1.1 million
- Vocabulary size: 65 unique characters
- Training split: 80%
- Validation split: 20%

The notebook downloads the dataset automatically during execution. No manual download is required.
